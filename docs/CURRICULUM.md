# Curriculum model

The course has 30 sequenced modules and 90 lessons. Each lesson renderer supplies the required structure: introduction, objectives, prerequisites, mechanics, architecture, implementation, runbook, failure scenarios, trade-offs, three exercises, five explained quiz questions, a practical challenge, references, and adjacent navigation.

Depth increases across four levels: Beginner (request and Go foundations), Intermediate (boundaries, APIs, data, containers), Advanced (brokers, workflows, Kubernetes, telemetry, delivery), and Expert (reliability, performance, cloud, incidents, architecture judgment, interview design, and capstone defense).

The commerce domain supplies a continuous case study. RabbitMQ is reserved for task delivery and Kafka for retained event streams; Redis is used for measured cache or ephemeral-state needs; PostgreSQL owns transactional records.
